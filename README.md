
# NSS Club Website

A responsive website for the National Service Scheme (NSS) at D. Y. Patil Institute of Technology, Pimpri, Pune.

The website aims to showcase NSS activities, promote social service, and help student volunteers explore events and community initiatives.

## ✨ Features

- 🏠 **Home Page** – Introduction to NSS and its motto, "Not Me, But You".
- ℹ️ **About NSS** – Information about the NSS and its objectives.
- 🤝 **Activities** – Showcases social service activities and initiatives.
- 📅 **Events** – Displays upcoming NSS events.
- ➕ **Create Event** – Allows volunteers to add new events.
- 📊 **Impact Section** – Highlights volunteer and community contributions.
- 🖼️ **Gallery** – Displays photos of NSS activities.
- 📩 **Contact Form** – Provides a way for visitors to send messages.
- ☰ **Sidebar Navigation** – Easy navigation between website sections.
- 📱 **Responsive Design** – Adapts to desktop, tablet, and mobile screens.
- 💾 **Local Storage** – Saves created events in the browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Browser Local Storage

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/diksha062302-spec/NSS-Website.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser, or use the Live Server extension.
